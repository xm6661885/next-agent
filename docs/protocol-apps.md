# Apps protocol

The Speech to text module is authenticated with the core cookie and exposes `/api/asr/settings` (`GET`, `PATCH`), `/api/asr/settings/test`, recording CRUD and processing routes under `/api/asr/recordings`, range capable `/audio`, and TXT/SRT `/export`. Settings are `api_base`, `api_key`, `model`, `language`, `prompt`, `chunk_sec`, and `retranscribe_on_finish`; the key is returned in clear. Recording objects retain the asr-web fields (`id`, `title`, `source`, `created_at`, `duration`, `status`, `error`, `size`, `segments`, `text`, `starred`, `progress`, `edited`). The global feed emits `{type:"asr_changed", module:"asr", id}` when recordings change.

Image generation uses `/api/imagegen/settings` (`GET`, `PATCH`), `/api/imagegen/settings/models`, `/api/imagegen/settings/test`, job listing/detail/delete/retry, multipart `POST /api/imagegen/jobs`, and authenticated `/api/imagegen/files/{id}/{name}`. Settings are `api_base`, `api_key`, `models`, `default_model`, `reference_mode`, and `timeout`. Jobs contain `id`, `prompt`, `params`, `model`, `references`, `status`, `error`, `images`, timestamps, duration and optional `revised_prompt`. Generation accepts prompt, model, size, quality, n, background, output format/compression, moderation, up to eight reference images and an optional mask. It emits `{type:"imagegen_changed", module:"imagegen", id, status}`.
